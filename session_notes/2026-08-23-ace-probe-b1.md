## Findings (the durable knowledge)

1. **Frozen-30 autopsy**: 16% correct overall, but the fatal metric was
   per-prompt: only 5/16 prompts had within-group variance (rest all-wrong
   or all-right). Group-relative RL gets zero gradient from both tails.
   Domain averages concealed this (access_policy "37.5%" was one prompt at
   6/8 carrying another at 0/8).

2. **Computation-shaped vs reasoning-shaped tasks.** Dead domains asked the
   model to enumerate (count 144 spanning trees), simulate (stack VM), or
   optimize over exponential spaces — impossible at 9B regardless of
   trajectory quality. Working transformation catalog:
   enumeration→certification, optimization→bounded construction,
   simulation→decisive-discrepancy replay, bookkeeping→small-hypothesis
   elimination.

3. **Correct traces are shorter than wrong ones** (frozen-30: 22k vs 25k
   mean; wrong median = 32k cap). Efficient search converges; failed search
   rambles into the backstop.

4. **Terminal verbatim loops.** ~20% of truncated traces enter zero-novelty
   repeat loops; only ~8% of truncated tokens are post-death. Landmark case
   p26 s2: solved and verified a coloring at ~8k tokens, then looped "I'll
   write the response now" for 24k tokens and never emitted the answer.
   Failure was in emission dynamics, not reasoning. Loop-onset states are
   the highest-headroom fork candidates for Phase 3 (solution present in
   working state, closure blocked).

5. **Throughput reality**: 3090 decode ~35 tok/s on torch fallback, ~38
   tok/s with FLA+causal-conv1d fast path. Kernel install is worth doing
   but is not the bottleneck (248k vocab + 8 full-attn layers are).

## Decisions with rationale

- **bf16, not q8**: this is measurement of Qwen3.5-9B; seeds are
  bf16-calibrated. Quantization changes the trajectory distribution —
  measuring Q8 is a different experiment.
- **Sequential generation**: batched long-trace generation OOMs 24GB cards.
- **26k backstop** (was 32k): user ruling — terminal loops contribute no
  information; a trace needing >26k to be right is a recorded model flaw.
  Existing 32k rows are never regenerated or truncated; chop analytically.
- **Reward architecture (settled)**: terminal verifiable reward with
  counterfactual fork credit; GRPO group baselines for the broad phase;
  amortized counterfactual critic (trained on fork outcomes) as the only
  legitimate dense signal. Forbidden as rewards: entropy, tortuosity,
  recurrence, length, judge/RLAIF scores — diagnostics, never targets.
- **Two-GPU split by candidate range**, not two full passes.
- **Fresh generator, not a Madlibz rework** — programmatic generation makes
  answers exact by construction and knobs machine-readable for calibration.
- **Hardware staging**: 3090s falsify through the Phase 3 fork-causality
  gate; H200 (Hopper, not Blackwell) only after a causal delta is shown.

## Environment traps encountered (fixes that worked)

- causal-conv1d has no prebuilt wheel; pip `nvidia-cuda-nvcc-cu12` ships
  ptxas but no nvcc. Working build: system nvcc 12.4 + `CC=gcc-13` +
  `pip install . --no-build-isolation`. (g++-15 exceeds CUDA 12.4's max;
  a cu13 nvcc mismatches torch cu128.)
- Two `nohup ... &` launches in one compound bash command mangle the
  second. Launch collectors in separate calls.
- pgrep in shell probes self-matches; use the `[c]ollect` bracket trick.
